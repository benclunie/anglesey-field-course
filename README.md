# Anglesey coastal identification resources

Student resources for **C6002C17 – Environment and Geography Field Course**, Harper Adams University.

The directory contains 42 annotated resources across birds, rockpools and strandline, seaweeds, coastal plants and Anglesey context. It includes direct links to 27 publisher-hosted PDF guides, alongside source pages and videos. The HAU/Entohub design uses Montserrat, the HAU logo, topic navigation and a light/dark toggle.

## GitHub Pages

In this repository’s **Settings → Pages**, select **Deploy from a branch**, **main**, **/(root)**, then save. The site has no build or package-install step. Keep `index.html`, `sources-and-credits.txt` and `.nojekyll` at the repository root.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Moodle

Once GitHub Pages has published, copy the live website address into a Moodle **URL** resource named **Anglesey coastal identification resources**.

Suggested description: “Identification guides for coastal birds, rockpool animals, seaweeds and dune and other coastal plants. Save the PDFs you need before travelling.”

## Updating the resource

Edit `index.html` to change the resource cards. Retain each resource’s publisher source link as an alternative route if the direct PDF URL changes. Update `sources-and-credits.txt` alongside any source changes.

## Credits

The identification PDFs remain on their original publishers’ websites and are not stored in this repository. Original authors, photographers and publishers retain their rights. HAU branding and typography follow the Entomology Hub; asset sources and resource-specific credits are recorded in `sources-and-credits.txt`.
